# Chaitanya Mehta — Free Trading Portfolio Website

This is a static website. It does not require a database or paid hosting.

## Free publishing with GitHub Pages

1. Create a free account at https://github.com/
2. Create a new public repository named:
   `YOURUSERNAME.github.io`
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. In GitHub: Settings → Pages → Source → Deploy from a branch.
5. Select `main` and `/root`, then Save.
6. Your website will appear at:
   `https://YOURUSERNAME.github.io`

## Before publishing

Replace:
- `YOUR_EMAIL@example.com`
- LinkedIn and Instagram `#` links
- Broker placeholders
- Performance placeholders
- Any project details you want changed
- Add your own photographs/logo in `assets/`

## Important

Keep trading performance labelled as live/verified/backtested/simulated.
If broker links become affiliate or IB links, add an explicit disclosure.
This website is informational and should not present trading outcomes as guaranteed.
